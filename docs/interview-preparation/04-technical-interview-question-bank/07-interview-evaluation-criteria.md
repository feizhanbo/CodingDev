# 面试评价与技术表达辨析

## 评分方法

每个主问题和每层追问按 0–3 分记录，分数只用于定位学习缺口，不预测录用结果。

| 得分 | 标准 |
| --- | --- |
| 0 | 关键机制错误，或把未实现能力说成现有事实 |
| 1 | 能描述功能/术语，但说不清调用链与失败边界 |
| 2 | 能结合源码讲清输入、状态变化、关键机制和限制 |
| 3 | 在2分基础上能推演失败窗口，给出替代方案及验证方法，明确证据边界 |

P0 目标至少2分；某题3分不抵消另一题对项目事实的夸大。若无法确认个人贡献，应诚实标记，不能用流利话术换分。

## 八道边界辨析题

### X01｜P0·高级｜“有 Checkpoint 就能完整恢复事务”对吗？

**考察/要点**：持久化范围。**参考回答**：不对，项目 checkpoint 保存图状态，文件和远端模型不属于它的事务；还要验证回执与摘要，未知工具副作用拒绝重放。**追问**：副作用后回执前崩溃？按 S01/T3，不根据日志猜成功。**原理/证据**：跨资源原子性，J。能画窗口是深入，只背“有持久化”不合格。

### X02｜P0·中级｜“JSON 输出合法，所以模型动作正确”对吗？

**考察/要点**：分层校验。**参考回答**：格式正确不证明工具合法、参数符合业务或结果正确；还需 Registry、权限和 Verifier。**追问**：改成 function calling 呢？仍需这些层。**原理/证据**：语法与语义，M/F/V；说严格输出解决幻觉是错误。

### X03｜P0·中级｜“独立测试绿了，全部验收条件完成”对吗？

**考察/要点**：覆盖边界。**参考回答**：不一定，coverage_for 多数自然语言条件未绑定检查；checks 通过不强制所有 coverage verified。**追问**：报告如何诚实表达？保留 uncovered 并说明测试范围。**原理/证据**：证据覆盖，V；深入能解释绑定缺口。

### X04｜P0·高级｜“prepared/completed 就是 exactly-once”对吗？

**考察/要点**：回执与原子提交区别。**参考回答**：不是，外部副作用和回执间有窗口，当前选择拒绝不确定重放，不能同时保证自动完成和不重复。**追问**：怎么提高自动恢复？按操作加入可验证幂等或远端结果查询。**原理/证据**：幂等协议，J；不得称为完整2PC。

### X05｜P0·中级｜“没有 shell，路径不越界，就能安全运行恶意仓库”对吗？

**考察/要点**：应用权限与 OS 权限。**参考回答**：不对，pytest 会执行 Python，仍可能访问宿主资源；当前是可信本地工具约束。**追问**：还缺什么？隔离、最小权限、网络与资源策略，见 S08。**原理/证据**：执行信任域，F/P。

### X06｜P0·高级｜“条件 UPDATE 解决所有并发与幂等”对吗？

**考察/要点**：不变量范围。**参考回答**：只保障条件语句匹配的更新资格；锁失败、多语句事务、下单请求身份、外部支付仍分别需要处理。**追问**：响应丢失重试？S06。**原理/证据**：原子更新与业务幂等，D。

### X07｜P0·初级｜“多个图节点就是多 Agent”对吗？

**考察/要点**：角色与编排。**参考回答**：当前一个 DeveloperAgent 做决策，其他节点执行服务职责；节点数不等于自主决策主体数。**追问**：真要多 Agent 先定义什么？职责、共享状态、权限、冲突与预算；当前未实现。**原理/证据**：Agent/Workflow 区别，R。

### X08｜P0·中级｜“本地回归全过，已经生产级”对吗？

**考察/要点**：验证范围。**参考回答**：本地测试不能证明多租户隔离、生产负载、真实模型效果与运维 SLO；应准确报告环境和测试类型。**追问**：优先验证什么？由目标场景决定，先识别 S08 的信任和并发边界。**原理/证据**：测试外推限制，E/P/R及历史验收文档。

## 自主训练与模拟面试

第一遍不看答案，每题用60–90秒回答“项目怎么做→为什么→一条限制”。第二遍让面试者依据回答选择树分支，不能提前背出下一层。第三遍打开源码核对，并记录错误是项目事实、原理、边界还是表达。

AI 路线模拟：O01/O02 → A04/A05 → T3 → A07/A08 → S08。后端路线：O02 → B04/B05 → T6 → B02/T4 → S05。建议一场只选两条树深入，其余做抽查，不机械问完全部题。

自评记录模板：日期｜题号｜原回答｜得分｜缺失证据｜正确边界｜下次复述。个人经历 O05 另补真实日志/过程，不依据参考答案杜撰。
