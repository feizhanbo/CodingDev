## 使用顺序

先确认贡献，再选岗位主线，练1分钟开场；选两个真正参与的案例深入。被追问时跳到第四阶段对应树，而不是继续背长稿。三种时长是练习目标，尚未由本人朗读计时；技术名词和停顿速度不同，必须用录音校准。

项目事实稿可以直接练习；带【待确认】的经历段属于填写模板，不能原样当成已确认个人成果。当前没有足够信息确认任何模块由本人独立负责，也不根据提交作者推断。最有价值的候选贡献是可信验收、回执恢复、生命周期治理、编排迁移和订单事务，实际选择取决于参与证据。
