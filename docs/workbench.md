# DevPilot 本地演示工作台

## 启动

在仓库根目录执行：

```powershell
.\workbench.ps1 -Build
```

首次构建需要 Node.js 20.19+、npm、Python 3.12+ 和 uv。访问 http://127.0.0.1:8765 。后续执行 `./workbench.ps1` 可复用已构建前端。

开发前端：在 `web` 下执行 `npm run dev`，Vite 将 `/api` 代理到本地 8765 端口。后端仍用上述启动脚本启动。修改前端后再次使用 `-Build` 更新正式预览。

模型配置只读取服务端 `devpilot/.env`。填写 `DEVPILOT_API_KEY`、`DEVPILOT_MODEL`；非 OpenAI 服务必须按供应商说明填写 `DEVPILOT_BASE_URL`，不能仅填写模型名。不要将密钥写入前端。启动脚本同时同步 ShopFlow 依赖；未显式指定测试解释器时优先使用该项目虚拟环境。目标 pytest 解释器通过 `DEVPILOT_TEST_PYTHON` 配置，应使用已安装 ShopFlow 依赖的环境。

## 界面使用

- 选择八个预置任务之一，或输入面向固定 ShopFlow 仓库的自定义需求及逐条验收条件。
- 点击“启动真实任务”。同一时间只允许一个任务；关闭浏览器不会取消后台任务。
- 查看执行事件、原始数据、运行结果、隐藏验收和代码 Diff。页面刷新后继续查看选中的运行。
- “流程自检：计算器修复”不调用模型，只验证运行链路，不表示订单任务已完成。
- 真实 DEV-001 结束后，在“业务效果”中运行对比，查看 paid 筛选、非法状态、无筛选三种实际接口结果。
- 已结束记录支持历史回放、暂停及倍速。旧 CLI 结果在服务启动时建立索引，来源与模型未知时明确标注，不计作真实模型成功。

## 架构与证据

React → FastAPI 本地 API → 独立 worker 进程 → 共享 bootstrap → 自研 Runtime / EvalRunner。

运行状态存放于 `devpilot/runs/web-jobs`；原始 Runtime 产物仍位于 `devpilot/runs/<run_id>`。事件增量轮询每秒一次。Web job 记录任务快照、模型、Git HEAD、实际 Python 源码摘要、进程 ID 和创建时间。服务重启时根据进程身份检查中断状态，不自动重放。

预置任务沿用 BenchmarkWorkspace 的缺陷起点与独立隐藏测试；自定义任务使用普通验证，不具有预置隐藏验收。completed 仅是执行结果，不意味着所有自然语言验收已证明。

业务对比读取实际候选工作区并制作带 SHA-256 的副本，缺陷起点与候选分别运行外部探针、创建独立临时 SQLite 数据库。`comparison.json` 保存请求、状态、响应、时间、候选摘要和逐项覆盖。探针不进入 Agent 可见工作区，不回灌隐藏测试。原始 Runtime 验证结果不被覆写。

仅绑定本机，限制 Host / Origin，不开放任意仓库、文件读取或 Shell 执行入口。仍属于可信本地代码执行环境，不是恶意代码安全沙箱。

## 五分钟演示路线

1. 解释 DEV-001 订单筛选需求和验收条件，指出自研 Runtime。
2. 启动真实任务，展示代码检索、计划、修改、测试及失败反馈。若耗时较长，使用明确标注的已完成历史回放。
3. 打开验证结果，区分 Runtime 状态、隐藏测试与未覆盖条件。
4. 打开 Diff，说明修改了哪些层、为何新增测试。
5. 运行业务对比，逐个点击三个案例，展示实际响应与候选摘要。

没有成功真实案例时，应展示失败原因和流程自检，不能将参考补丁测试或 Fake 运行宣传为真实模型成果。
